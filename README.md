# Folk Games (লোকখেলা)

Android downloads. অ্যান্ড্রয়েডের জন্য ডাউনলোড।

## Download for Android

**On your phone, open this link (or scan the QR code):**

https://github.com/Nil20/folk-games-app/releases/latest/download/folk-games.apk

The link always serves the newest build.

0. **Back up before installing a new version or uninstalling.** A normal update keeps your
   progress, but the backup code is your safety net (see [Keep your progress](#keep-your-progress)).
1. Download `folk-games.apk`.
2. Open the downloaded file. Android asks you to allow **Install unknown apps** for your browser
   (or file manager). Allow it once.
3. If Play Protect warns you, tap **More details → Install anyway**.
4. Open **Folk Games**. It runs full screen in landscape.

০. **নতুন সংস্করণ ইনস্টল করার আগে বা আনইনস্টল করার আগে ব্যাকআপ নিন।** সাধারণ আপডেটে অগ্রগতি থেকেই যায়,
তবু ব্যাকআপ কোডটা আপনার নিরাপদ ভরসা ([অগ্রগতি সংরক্ষণ](#অগ্রগতি-সংরক্ষণ) দেখুন)।

ডাউনলোড করে ফাইলটি খুলুন। "অজানা উৎস থেকে অ্যাপ ইনস্টল" অনুমতি চাইলে ব্রাউজারের জন্য একবার অনুমতি দিন।
Play Protect সতর্ক করলে **আরও বিবরণ → তবুও ইনস্টল করুন** চাপুন।

**"App not installed"?** You probably have an older test (debug) build. **Back up first** (see
below), then uninstall it once, install again and restore. After that, updates install over the top
and keep your progress.

**"App not installed"?** সম্ভবত আপনার ফোনে আগের কোনো টেস্ট (ডিবাগ) সংস্করণ আছে। **আগে ব্যাকআপ নিন**
(নিচে দেখুন), তারপর একবার আনইনস্টল করে আবার ইনস্টল করুন এবং ফেরত আনুন। এরপর আপডেট সরাসরি তার ওপরেই
বসবে, অগ্রগতি থেকে যাবে।

## Keep your progress

1. **Back up:** open **Settings → Backup and restore → Copy code**. Save the code somewhere safe,
   such as a note or a message to yourself.
2. **Restore:** on the new phone, or after reinstalling, open the same screen, tap **Restore**,
   paste the code and tap **Check code**. The game shows the level, stars and matches in the code and
   asks before it replaces anything. **Undo** is available right after.
3. **Before uninstalling** (for example to fix "App not installed"): back up first, then uninstall,
   install, and restore.

## অগ্রগতি সংরক্ষণ

1. **ব্যাকআপ:** **সেটিংস → ব্যাকআপ ও ফেরত আনা → কোড কপি করো** চাপুন। কোডটা কোথাও নিরাপদে রাখুন,
   যেমন কোনো নোটে বা নিজেকে পাঠানো মেসেজে।
2. **ফেরত আনা:** নতুন ফোনে, বা আবার ইনস্টল করার পর, একই পর্দায় গিয়ে **ফেরত আনো** চাপুন, কোড পেস্ট করে
   **কোড যাচাই করো** চাপুন। কোডে থাকা লেভেল, তারা আর খেলার সংখ্যা দেখিয়ে খেলাটা জিজ্ঞেস করবে, তারপর বদলাবে।
   বদলানোর পরেই **আগের মতো করো** চাপলে আগের অবস্থায় ফেরা যায়।
3. **আনইনস্টলের আগে** (যেমন "App not installed" ঠিক করতে): আগে ব্যাকআপ নিন, তারপর আনইনস্টল, ইনস্টল
   এবং ফেরত আনুন।

## Stay up to date

The game tells you when a new version is ready (**Update now**). You can also open the link above
again and install over the old version.

নতুন সংস্করণ এলে গেমের ভেতরেই **Update now** দেখাবে। চাইলে ওপরের লিংক আবার খুলে পুরনোটির ওপর ইনস্টল করতে পারেন।
