# Folk Games (লোকখেলা)

Traditional Bangladeshi outdoor games, rebuilt for your phone. Landscape, offline, in Bangla and
English. The first game is **Kanamachi** (blind man's buff): play against AI kids, unlock new
friends and rivals, and collect looks as you win.

বাংলাদেশের ঐতিহ্যবাহী মাঠের খেলা, এবার ফোনে। অফলাইনে চলে, বাংলা ও ইংরেজি দুই ভাষাতেই।
প্রথম খেলা **কানামাছি**: কম্পিউটারের খেলোয়াড়দের বিরুদ্ধে খেলুন, নতুন বন্ধু ও প্রতিদ্বন্দ্বী খুলুন।

## Keep your progress

1. **Back up:** open **Settings → Backup and restore → Copy code**. Save the code somewhere safe,
   such as a note or a message to yourself.
2. **Restore:** on the new phone, or after reinstalling, open the same screen, tap **Restore**,
   paste the code and tap **Check code**. The game shows the level, stars and matches in the code and
   asks before it replaces anything. **Undo** is available right after.
3. **Before uninstalling** (for example to fix "App not installed"): back up first, then uninstall,
   install, and restore.

## অগ্রগতি সংরক্ষণ

1. **ব্যাকআপ:** **সেটিংস → ব্যাকআপ ও ফেরত আনা → কোড কপি করো** চাপুন। কোডটা কোথাও নিরাপদে রাখুন,
   যেমন কোনো নোটে বা নিজেকে পাঠানো মেসেজে।
2. **ফেরত আনা:** নতুন ফোনে, বা আবার ইনস্টল করার পর, একই পর্দায় গিয়ে **ফেরত আনো** চাপুন, কোড পেস্ট করে
   **কোড যাচাই করো** চাপুন। কোডে থাকা লেভেল, তারা আর খেলার সংখ্যা দেখিয়ে খেলাটা জিজ্ঞেস করবে, তারপর বদলাবে।
   বদলানোর পরেই **আগের মতো করো** চাপলে আগের অবস্থায় ফেরা যায়।
3. **আনইনস্টলের আগে** (যেমন "App not installed" ঠিক করতে): আগে ব্যাকআপ নিন, তারপর আনইনস্টল, ইনস্টল
   এবং ফেরত আনুন।
